Lichtschranke

In diesem Beispiel baust du mit der weißen LED als Lichtquelle, der Photodiode als Helligkeitssensor und einem Reflektor eine Lichtschranke auf. Sobald der Helligkeitswert im Vergleich zur letzten Messung stark abfällt, schaltet das Programm die RGB-LED auf Rot, aktiviert den Summer und wartet, bis der Taster gedrückt wird. Danach wird alles wieder zurückgesetzt.

Funktionsweise

  • Die weiße LED an Pin 15 wird als Lichtquelle eingeschaltet.
  • Die Photodiode an Pin 28 misst die Lichtintensität.
  • Wenn der Wert im Vergleich zur letzten Messung stark abfällt, wird eine Unterbrechung erkannt.
  • Die RGB-LED zeigt den Status an: zuerst grün, bei einer Erkennung rot.
  • Der Summer piept, bis der Taster auf Pin 1 gedrückt wird.

Quellcode

Datei main.py 

from machine import Pin, ADC, PWM
import time

rgbRedLedPin = PWM(Pin(9))
rgbGreenLedPin = PWM(Pin(7))
rgbBlueLedPin = PWM(Pin(8))
buttonPin = Pin(1, Pin.IN, Pin.PULL_UP)
photodiodePin = ADC(Pin(28))
whiteLedPin = Pin(15, Pin.OUT)
buzzerPin = PWM(Pin(16))

# RGB-LED vorbereiten.
rgbRedLedPin.freq(1000)
rgbGreenLedPin.freq(1000)
rgbBlueLedPin.freq(1000)

_DUTY_SCALE = 65535 / 256

def setRgbLed(r, g, b):
    # Farbwerte von 0 bis 255 auf den PWM-Bereich umrechnen.
    rgbRedLedPin.duty_u16(int(r * _DUTY_SCALE))
    rgbGreenLedPin.duty_u16(int(g * _DUTY_SCALE))
    rgbBlueLedPin.duty_u16(int(b * _DUTY_SCALE))

def buzzerOn(freq):
    buzzerPin.freq(freq)
    buzzerPin.duty_u16(32767)

def buzzerOff():
    buzzerPin.duty_u16(0)

whiteLedValue = 0

def toggleWhiteLed():
    global whiteLedValue
    # Zwischen an und aus wechseln.
    whiteLedValue = not whiteLedValue
    whiteLedPin.value(whiteLedValue)

def run_light_gate():
    # Startzustand: Licht an, LED gruen.
    toggleWhiteLed()
    setRgbLed(0, 255, 0)

    last_photo = -1

    while True:
        # Neuen Helligkeitswert lesen.
        photo = photodiodePin.read_u16()

        # Faellt der Wert im Vergleich zur letzten Messung stark ab,
        # ist etwas im Lichtweg.
        if last_photo != -1 and last_photo - photo > 1000:
            setRgbLed(255, 0, 0)
            toggleWhiteLed()
            buzzerOn(2000)

            # Warten, bis die Taste gedrueckt wird.
            while buttonPin.value() == 1:
                time.sleep(0.05)

            buzzerOff()
            setRgbLed(0, 255, 0)
            toggleWhiteLed()
            # Danach beginnt die Messung wieder von vorn.
            last_photo = -1

        last_photo = photo
        time.sleep(0.1)

run_light_gate()
