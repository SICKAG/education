Der IoT Sensor

Überblick

Das IoT-Sensor-Set besteht aus einem Raspberry Pi Pico 2 W und einer Platine mit verschiedenen Bauteilen wie LED, Taster, Photodiode, Buzzer, RGB-LED und Display. Zusätzlich sind ein kleiner Reflektor und ein USB-Kabel enthalten.

Pinbelegung

Um die Bauteile mit dem Raspberry Pi Pico anzusteuern, ist es wichtig zu wissen, welches Bauteil an welchen Pin angeschlossen ist. Die folgende Tabelle gibt einen Überblick, welcher Pin des Raspberry Pi Pico über die Platine mit welchem Bauteil verbunden ist und gibt eine kurze Erklärung für die Zuordnung.

Pin Funktion Erklärung
GP1 Taster Der Taster ist verbunden mit einem GPIO Pin, um einlesen zu können, ob der Taster gedrückt ist (Eingabe 0) oder nicht (Eingabe 1).
GP2 Bildschirm SDA Der Bildschirm wird mit I2C angesteuert. GP2 wird als Serial-Data-Pin (SDA-Pin) verwendet.
GP3 Bildschirm SCL Der Bildschirm wird mit I2C angesteuert. GP3 wird als Serial-Clock-Pin (SCL-Pin) verwendet.
GP7 RGB-LED Grün Damit der Grünanteil der RGB-LED dimmbar ist, wird dieser an einen PWM-fähigen Pin angeschlossen.
GP8 RGB-LED Blau Damit der Blauanteil der RGB-LED dimmbar ist, wird dieser an einen PWM-fähigen Pin angeschlossen.
GP9 RGB-LED Rot Damit der Rotanteil der RGB-LED dimmbar ist, wird dieser an einen PWM-fähigen Pin angeschlossen.
GP15 LED-Front Für die vorne angebrachte weiße LED genügt ein einfacher GPIO-Pin.
GP16 Buzzer (Lautsprecher) Der Buzzer muss mit einem PWM-fähigem Pin verbunden werden, da so die Frequenz des Tones verändert werden kann.
GP28 Photodiode einlesen Für die Photodiode wird ein GPIO-Pin mit ADC verwendet, um den Messwert zu lesen.

Raspberry Pi Pico

In diesem Abschnitt folgen allgemeine Infos zum Raspberry Pi Pico. Es handelt es sich um ein Mikrocontroller-Board, das einfach programmiert werden kann. Je nach Modell ist im Raspberry Pi Pico ein WLAN- und Bluetoothmodul integriert.

Der Raspberry Pi Pico hat insgesamt vierzig Pins, die unterschiedliche Funktionen haben. Die folgende Grafik zeigt, welche Pins welche Funktion haben.

Ground (GND)

GND‑Pins (kurz für „Ground“) sind der gemeinsame Bezugspunkt einer Schaltung. Alle Spannungen werden im Verhältnis zu GND gemessen. Wird zum Beispiel eine LED an Pin 4 eines Mikrocontrollers angeschlossen, muss die LED zusätzlich mit einem GND‑Pin verbunden werden. Erst dadurch ist der Stromkreis geschlossen und die LED kann leuchten.

Power

Power Pins sind Ausgänge, an denen die Betriebsspannung des Mikrocontrollers anliegt. Beim Raspberry Pi Pico 2 W sind das 3,3 V. Die Spannung an den Power-Pins ist konstant und kann nicht verändert werden.

GPIO, PIO

GPIO steht für general-purpose input/output. Die Pins werden hauptsächlich für zwei Aufgaben verwendet:

  • Die Spannung an den GPIO-Pins kann durch die Programmierung des Mikrocontrollers verändert werden. Dabei kann sie nur ein- oder ausgeschaltet sein. So lässt sich zum Beispiel eine LED steuern.
  • Die Spannung an den GPIO-Pins kann auch eingelesen werden. Ohne Analog-zu-Digital-Konverter steht das Ergebnis nur digital zur Verfügung. Das heißt: Es kann nur unterschieden werden, ob eine Spannung anliegt oder nicht.

PIO steht für programmable input/output. PIO-Pins haben dieselben Funktionen wie GPIO-Pins. Der einzige Unterschied liegt in der technischen Realisierung der Funktionen.

ADC

ADC ist die Abkürzung für Analog-zu-Digital-Konverter. Die an einem ADC-Pin anliegende Spannung kann genauer gemessen werden als an normalen GPIO-Pins. Die Anzahl der Bits eines ADC bestimmt die Genauigkeit des Messwerts. Der Raspberry Pi Pico verwendet 12-Bit-ADCs. Dabei wird die anliegende Spannung als Wert zwischen 0 und 4095 ausgegeben. Das sind insgesamt $2^{12} = 4096$ mögliche Werte. Alle Spannungswerte von 0 bis $(1/4096)$ der Maximalspannung ergeben dabei den Messwert 0.

PWM

PWM steht für Pulsweitenmodulation. Es handelt sich um eine Technik, mit der die mittlere Leistung eines elektrischen Signals gesteuert wird. Das Signal wird dabei periodisch sehr schnell an- und ausgeschaltet. Der Vorgang ist unten grafisch dargestellt. Das Verhältnis der Impulsdauer zur Periodendauer nennt man Tastgrad. Mit dieser Technik ist es möglich, LEDs zu dimmen, indem zum Beispiel für 2 Millisekunden Strom fließt und anschließend für 8 Millisekunden keiner. Der Tastgrad beträgt in diesem Beispiel 20%. Das bedeutet, die LED ist bei 20% ihrer vollen Helligkeit. Das funktioniert nur, wenn der Wechsel so schnell erfolgt, dass das menschliche Auge ihn nicht mehr als solchen wahrnimmt.

Bildquelle: www.elektronik-kompendium.de [Externer Link]

I2C

Bei I2C handelt es sich um einen seriellen Datenbus, der zur Übertragung von Daten zwischen verschiedenen Geräten verwendet wird. I2C arbeitet nach dem Master-Slave-Prinzip (auch Controller-Peripheral-Prinzip). Das bedeutet, dass nur das Master-Gerät unaufgefordert senden darf. Alle Slave-Geräte antworten nur, wenn sie dazu aufgefordert werden. Es kann mehrere Slave-Geräte geben, da diese über Adressen eindeutig identifizierbar sind.

Für die Datenübertragung verwendet I2C zwei Leitungen:

  • Die Taktleitung dient dem Takten der Datenübertragung. Dafür wird der SCL-Pin (kurz für Serial-Clock) verwendet.
  • Die Datenleitung dient dem tatsächlichen Übertragen der Daten. Dafür wird der SDA-Pin (kurz für Serial Data) verwendet.
