Support & FAQ

Hier findest du Antworten auf häufig gestellte Fragen und zusätzliche Ressourcen, damit du bestmöglich mit deinem IoT-Sensor arbeiten kannst.

FAQ

Was ist der IoT-Sensor

Der IoT-Sensor ist eine Platine, die zur Verwendung mit einem Raspberry Pi Pico konstruiert ist. Mit dem Raspberry Pi Pico können die Bauteile auf dem IoT-Sensor angesteuert sowie Messdaten ausgelesen und angezeigt werden.

Der IoT-Sensor ist ideal für Schüler*innen, um den Umgang mit Sensoren und Mikrocontrollern zu lernen. Für Fortgeschrittene bieten die Komponenten des IoT-Sensors viele Möglichkeiten für kreative Projekte.

Wie wird der Raspberry Pi Pico programmiert?

Für die Programmierung des Raspberry Pi Pico benötigst du eine integrierte Entwicklungsumgebung (IDE). Falls du noch keine hast, schau mal im Bereich "Entwicklungsumgebung" vorbei.

In der Entwicklungsumgebung wird der Code geschrieben, der auf dem Raspberry Pi Pico ausgeführt werden soll. Der Code wird anschließend auf den Speicher des Raspberry Pi Pico übertragen.

Was passiert, wenn ich den IoT-Sensor per USB-Kabel anschließe?

Der Raspberry Pi Pico führt das Programm aus, das zuletzt übertragen wurde, auch wenn er zwischenzeitlich von der Stromversorgung getrennt war. Das Programm befindet sich im nichtflüchtigen Speicher des Raspberry Pi Pico und bleibt deshalb erhalten.

Wie lösche ich ein Programm auf den Raspberry Pi Pico?

Ein Programm auf dem Raspberry Pi Pico kann nicht im herkömmlichen Sinne gelöscht werden. Du kannst allerdings eine leere main.py übertragen. Dadurch wird das vorherige Programm durch eine leere Datei überschrieben.
