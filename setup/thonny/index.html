Python Entwicklungsumgebung Thonny

Zum Schreiben des Codes für den Raspberry Pi Pico brauchst du eine integrierte Entwicklungsumgebung (IDE). Für den Einstieg empfehlen wir die Python-IDE Thonny.

Installation

Folgende Anleitung zeigt dir, wie du Thonny installierst.

1
Öffne die Thonny-Website. Du findest sie unter diesem Link:
thonny.org [externer Link]
2
Wähle im Menü oben rechts die passende Version für dein Betriebssystem aus.

3
Öffne den Setup-Dialog, indem du die heruntergeladene Datei per Doppelklick startest.
4
Folge den Anweisungen im Setup-Dialog. Starte die Installation mit "Installieren".
5
Sobald die Installation abgeschlossen ist, kannst du Thonny öffnen.
Drücke dafür die ⊞-Taste und gib "Thonny" in die Suchleiste ein.
6
Beim ersten Öffnen kannst du die Sprache auf Deutsch stellen.

Konfiguration

In Thonny musst du einige Einstellungen vornehmen, damit du den Raspberry Pi Pico programmieren kannst. Öffne Thonny und führe die folgenden Schritte aus:

1
Klicke in der Navigationsleiste auf "Ansicht" und schalte die Option "Dateien" ein.
2
Verbinde den Raspberry Pi Pico über das USB-Kabel mit deinem PC.
3
Klicke unten rechts in der Statusleiste von Thonny auf den dort angezeigten Text. Es öffnet sich eine Auswahl an verfügbaren programmierbaren Geräten. Der Raspberry Pi Pico sollte in der Liste auftauchen. Wenn du ihn auswählst, werden links im Abschnitt "Dateien" unter der Überschrift Raspberry Pi Pico die Dateien auf dem Raspberry Pi Pico angezeigt.

4

Auf dem Raspberry Pi Pico sollte eine Datei mit dem Namen main.py vorhanden sein. Öffne diese mit einem Doppelklick. Falls die Datei main.py nicht vorhanden ist, rechtsklicke auf den Bereich unterhalb der Überschrift "Raspberry Pi Pico" und wähle die Option "Neue Datei". Nenne die Datei main.py und bestätige mit "Ok". Die Datei taucht nicht sofort in der Datei-Übersicht auf, sondern erst nachdem sie einmal gespeichert wurde.

Dein Erstes Programm

Nachdem du Thonny erfolgreich installiert und eingerichtet hast, bist du bereit für dein erstes Programm.

1

Gib den folgenden Code in die erste Zeile der Datei main.py auf dem Raspberry Pi Pico ein und speichere die Änderung mit Strg + S. 

print("Hallo Welt!")

2
Führe das Programm aus, indem du auf den grünen Kreis mit weißem Pfeil drückst. In der Kommandozeile sollte der Text "Hallo Welt!" erscheinen.
